# 個人投資紀錄網站 v1.1

> 純靜態 HTML + JavaScript 的台股投資組合管理工具。資料由 Excel 匯入，所有自建紀錄與設定存在瀏覽器 localStorage。

---

## 快速開始

1. 雙擊打開 `index.html`（建議用 Chrome 或 Edge）
2. 輸入預設密碼 **`mystock2026`** 登入
3. 登入後到「設定」分頁可改密碼

---

## 檔案結構

```
mystock/
├── 股票.xlsx                  原始資料（你的真相來源）
└── web/
    ├── index.html             主頁
    ├── app.js                 前端邏輯
    ├── data.js                從 Excel 解析的資料（自動產生，勿手動編輯）
    ├── rebuild_data.py        Excel 改完 → 重建 data.js
    ├── fetch_prices.py        命令列備援抓股價
    └── README.md              本文件
```

## 功能總覽

### 主要分頁

| 分頁 | 內容 |
|---|---|
| **總覽** | 6 張 KPI 卡（總成本、現值、未實現、已實現、配息、總報酬） + 持股圓餅圖（含張數） + 每月配息柱狀圖 |
| **持股明細** | 每檔的均價、市值、配息率、不含息/含息報酬，全欄可排序，可獨立切換 我/Max 視角 |
| **交易紀錄** | 每筆買賣的扣完手續費 + 證交稅後實際報酬率與年化報酬，可篩選 + 排序 + 編輯 |
| **配息紀錄** | 所有配息（已收 + 預估），可篩選股票/年份/類型；✏️ 改金額；自動推估有「自動」標籤 |
| **每月配息** | 4 張累計卡 + 每月圖 + 年度匯總 + 月度明細（含累計欄） |
| **➕ 新增** | 表單：買進、賣出、配息、配股；底部「已自建紀錄」清單可修改/刪除；新增買進有近期成交價參考 |
| **配息預估** | 各股票自訂殖利率參數（每股配息 + 月/季/半年/年配） |
| **股價更新** | ⚡ 即時最新 / 🔄 昨日收盤；只列現持股；可手動覆寫 |
| **設定** | 密碼、手續費率、證交稅、匯出/匯入 JSON、清除本機資料 |

### 關鍵特色

- **三人視角切換**：頂端可切「合併 / 我 / Max」（支援多人投資組合）
- **持股明細獨立篩選**：可在持股明細頁單獨切換 我/Max，不影響其他分頁
- **報酬率扣費**：每筆交易計算手續費 0.1425% + 證交稅（股票 0.3%、ETF 0.1%），支援券商折扣費率
- **配息智能推算**：未來配息金額 = 除息日當下持股 × 每股配息（自動回放交易紀錄）
- **✏️ 鎖定機制**：手動 ✏️ 改過的配息金額不會被自動覆寫
- **買進參考**：「➕ 新增買進」表單下方顯示近 10 筆均/高/低，跟現價跟你打算買價的偏離
- **股價兩種抓法**：即時最新（盤中當下成交）/ 昨日收盤（前一交易日）
- **總計含歷史**：持股明細的總計列「已收配息／已實現／含息／不含息」永遠包含已賣光的股票（與總覽 KPI 對齊）

## 資料儲存機制

### Excel（真相來源）

`股票.xlsx` 是所有原始紀錄。修改 Excel 後執行：

```bash
cd mystock\web
python rebuild_data.py
```

會重建 `data.js`，瀏覽器 Ctrl+Shift+R 強制重新整理就會看到新資料。

> **重要**：openpyxl 重存 Excel 時會清掉公式 cache。Excel 內已知公式（買進金額 / 配息 / 配股 / 市值）已全部轉成數值；rebuild_data.py 額外有 `FALLBACK_PRICES` 內建一份最後已知現價作為保底。

### 瀏覽器 localStorage（自建/設定）

以下資料存在你的瀏覽器中，不會寫回 Excel：

| Key | 內容 |
|---|---|
| `mystock.pwHash` | 密碼 SHA-256 |
| `mystock.prices` | 各股票自訂價格 |
| `mystock.priceMeta` | 報價更新時間與來源 |
| `mystock.fee` | 手續費率與證交稅設定 |
| `mystock.fc` | 配息預估參數（殖利率） |
| `mystock.userRecords` | 在網站新增的買進/賣出/配息/配股紀錄 |
| `mystock.overrides` | Excel 紀錄的覆寫（賣出標記、配息金額調整等） |

**重要**：清瀏覽器資料、換瀏覽器、用無痕模式都會丟失上述資料。建議定期到「設定」匯出 JSON 備份。

## 計算公式

### 手續費與證交稅（預設值，可在設定改）

```
買進手續費 = max(round(買進金額 × 0.1425%), 20)
賣出手續費 = max(round(賣出金額 × 0.1425%), 20)
證交稅 = round(賣出金額 × 0.3%)   // 股票
證交稅 = round(賣出金額 × 0.1%)   // ETF
```

### 報酬率（已賣出）

```
買進成本   = 成交價 × 股數 + 買進手續費
賣出淨收   = 成交價 × 股數 − 賣出手續費 − 證交稅
損益       = 賣出淨收 − 買進成本
報酬率     = 損益 / 買進成本
年化報酬率 = (1 + 報酬率)^(365/持有天數) − 1
```

### 報酬率（未賣出）

```
未實現損益   = 市值 − (成交價 × 股數)         // 不含買費，跟 Excel 對齊
未實現%      = 未實現損益 / (成交價 × 股數)
```

> **注意**：總覽/持股明細的「總投資成本」用「成交價×股數」（與 Excel 一致）。個別交易紀錄的報酬率仍含手續費（精確）。

### 持股明細的「不含息」vs「含息」

```
不含息損益    = 未實現損益 + 已實現損益
不含息%       = 不含息損益 / 總成本

含息總損益    = 未實現 + 已實現 + 已收配息
含息報酬%     = 含息總損益 / 總成本

配息率%       = 已收配息 / 總成本
```

### 配息（除息日當下持股）

```
holdingsAtDate(代碼, 除息日) =
   sum(在除息日「之前」買進，且在除息日「當下」未賣出的批次股數)
 + sum(在除息日「之前」獲得的配股股數)

預估配息金額 = holdingsAtDate(代碼, 除息日) × 每股配息
```

未來配息（除息日 > 今日）若無 ✏️ 鎖定，金額會即時依當下持股重算；過去配息（除息日 ≤ 今日）一律用儲存值。

## 使用流程

### 1. 日常 — 看現況

打開網站 → 自動載入。「總覽」頁直接看當前狀態。

### 2. 更新股價

「股價更新」分頁 → 按 ⚡ 即時最新（盤中）或 🔄 昨日收盤 → 抓完所有頁面自動重算。

### 3. 新增交易

「➕ 新增」分頁 → 選對應的表單填寫 → 儲存 → 立即併入持股計算。

### 4. 改錯

「➕ 新增」分頁底部「已自建紀錄」表格 → 點 **修改** 或 **刪除**。  
也可以在「交易紀錄」分頁找到那筆，點右邊 ⋮ 進選單。

### 5. 重要更動後備份

「設定」分頁 → 點「匯出設定 JSON」 → 存到 mystock 資料夾備份。

### 6. Excel 加新交易（適合大量補登）

編輯 `股票.xlsx` → 命令列：

```bash
python rebuild_data.py
```

→ 瀏覽器 Ctrl+Shift+R。

## 維運

### 自動抓股價

兩條路：

1. **網站直接抓**（推薦）：「股價更新」頁按按鈕，會走公開 CORS proxy 打 TWSE MIS API。
   - ⚡ 即時最新：用 z 欄（當下成交價）
   - 🔄 昨日收盤：用 y 欄（前一交易日收盤）
2. **命令列備援**：當 proxy 都不通時，可在本機跑 `python fetch_prices.py`，會輸出 `prices.json`，然後手動把數字貼進「股價更新」欄位。

### 修改密碼

「設定」分頁 → 新密碼 + 確認 → 儲存 → 下次登入生效。

### 改手續費為券商折扣費率

「設定」分頁 → 手續費率 → 例如改 0.04275（3 折）→ 儲存。

### 新買到 Excel 沒有的股票

直接在「➕ 新增買進」填代碼即可。但下拉選單只列 Excel 已知的股票，所以新代碼要先在 Excel 加一筆任何紀錄（買進或配息），跑 rebuild_data.py，網站才會出現在下拉選項。

### 修正既有資料

| 種類 | 自建紀錄（你在網站新增的） | Excel 原始紀錄 |
|---|---|---|
| 買進 | 「➕ 新增」分頁底部 → 修改 / 刪除 | 改 Excel → rebuild_data.py |
| 賣出（標記在某筆買進上） | 「➕ 新增」分頁底部 → 修改 / 移除 | 同上 |
| 配息 | 「配息紀錄」→ ✏️ 改值；自建可刪 | 「配息紀錄」→ ✏️ 改值（會疊 override，可 ↺ 還原）|
| 配股 | 自建區可刪除重加 | 改 Excel → rebuild_data.py |

## 已知限制

- **沒有部分股數賣出**：目前只能整批標記為已賣。如要拆批，先在 Excel 拆成兩列再 rebuild
- **Excel 紀錄不能在網站直接改買賣**（只有「自建」紀錄可改）：因為 rebuild 會把 Excel 蓋回去；目前只有配息有 override 機制可在網站修改
- **股價只在點擊時才抓**：沒有自動定時更新
- **沒有歷史價格走勢圖**：只能看當前快照
- **單機 + 單瀏覽器**：自建資料不會跨裝置同步，定期匯出 JSON 備份
- **公式尾差**：Excel 公式產生的小數（如配息 5,767.2）保留原始浮點，加總可能跟 Excel 顯示差幾毛錢

## 技術細節

- **前端**：HTML + Vanilla JavaScript（無 framework）
- **CSS**：自寫，深色主題
- **圖表**：Chart.js 4.4 (CDN)，圓餅圖用自訂 HTML legend（可顯示張數+百分比）
- **密碼**：SHA-256 hash 存 localStorage（純前端驗證，不適合敏感場景）
- **資料**：Excel → openpyxl 解析 → JSON 嵌進 data.js
- **股價來源**：TWSE 即時資訊 API (`mis.twse.com.tw`)，透過公開 CORS proxy（corsproxy.io / allorigins / codetabs）
