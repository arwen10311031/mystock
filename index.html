計算規則
假設「持股不再變動」的情況下，今年會領到的配息：
1. 入帳日 ≤ 今日 的紀錄 → 用實際金額（已收）
2. 入帳日 > 今日 的紀錄 → 用「除息日當下持股 × 每股配息」自動算（預估剩餘）
3. 如果某筆預估金額你已經 ✏️ 鎖定（例如知道實際發放數），那筆就不再自動覆寫
4. 殖利率 = 全年合計 / 對應股票的成本（成交價×股數）

股價更新

抓取方式（從穩到不穩）：⚡/🔄 GAS（你的 Apps Script 直連 TWSE，最穩）→ 📡 官方 API（TWSE OpenAPI 收盤）→ 📋 貼上 JSON（本機 fetch_prices.py）→ ⚡/🔄 即時/昨收（走公開 CORS proxy，可能掛）：
⚡ 即時最新：交易時段內為當下成交價；非交易時段則為當天 (或最近一個交易日) 收盤價。
🔄 昨日收盤：永遠抓前一個交易日的收盤價。
抓不到時會自動換下一個 proxy；都失敗就手動填、或執行同層的 fetch_prices.py。
